# Notebooks Directory

This directory contains Jupyter notebooks for exploratory data analysis, model development, and visualization.

## Notebooks

- `music_recommendation.ipynb` - Main analysis notebook
- `data_exploration.ipynb` - EDA and data understanding
- `model_evaluation.ipynb` - Model performance analysis
- `feature_analysis.ipynb` - Feature importance and engineering

## Usage

```bash
# Start Jupyter
jupyter lab

# Or use the specific notebook
jupyter notebook notebooks/music_recommendation.ipynb
```

## Best Practices

- Clear outputs before committing to Git
- Use descriptive cell titles
- Include markdown explanations
- Save intermediate results to `data/processed/`
